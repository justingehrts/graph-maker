# Fonts

Proxima Nova font files (`.ttf`) for the charts. Keep each file's original name.

The charts use three weights from the Weather Impact 2.0 style guide:

| Text | File |
|---|---|
| Data labels and call-outs | `proximanova-extrabold.ttf` |
| X axis labels | `proximanova-bold.ttf` |
| Y axis numbers | `proximanova-semibold.ttf` |

The rest of the family is here for future use. Proxima Nova is a commercial font, so make sure you're licensed to use and distribute it. Without the three files above, the app falls back to the default sans-serif font.
